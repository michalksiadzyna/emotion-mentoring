Architecture

  • Static HTML, single-page approach per language. All CSS and JS inline per page.
  • Hosted on GitHub Pages. Repository: private.
  • No build tools, no frameworks, no CMS. Raw HTML/CSS/JS.
  • Domain: emotionmentoring.com

Design System

  • Dark luxury aesthetic: #141418 background, #c9a96e gold, #f5f3ee white
  • Fonts: Playfair Display (headings) + Barlow (body)
  • Transition speed: 0.1s (0.3s rejected). FAQ accordion: 0.4s exception.
  • Comprehensive hover system: gold accents, subtle lifts, grouped hover zones
